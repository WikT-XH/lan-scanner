# 局域网IP扫描工具 lan-scanner

## 项目介绍
基于 Python 标准库实现的轻量级局域网主机端口扫描工具，无需安装第三方依赖，并发探测指定网段内主机的端口开放情况，自动解析主机名并支持结果导出。

## 功能特性
- 支持任意网段（CIDR 格式），默认 `192.168.1.0/24`
- 支持一次扫描多个端口（逗号分隔）
- 50 线程并发扫描，实时显示进度
- 自动解析存活主机的主机名
- 扫描结果导出为 TXT 文件（UTF-8 编码）
- 网段、端口、超时、线程数、导出路径均可通过命令行参数配置
- 纯 Python 标准库实现，零额外依赖，跨平台

## 运行环境
- Python 3.7 及以上版本

## 使用方法
```bash
python lan_scan.py [-n 网段] [-p 端口列表] [-t 超时秒] [-w 线程数] [-o 导出文件]
```

### 参数说明
| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| `-n, --network` | 要扫描的网段，如 `192.168.1.0/24` | `192.168.1.0/24` |
| `-p, --ports` | 端口列表，逗号分隔，如 `80,443,22` | `80` |
| `-t, --timeout` | 单次连接超时（秒） | `0.8` |
| `-w, --workers` | 并发线程数 | `50` |
| `-o, --output` | 结果导出文件路径，不填则不导出 | 无 |

### 示例
```bash
# 扫描默认网段的 80 端口
python lan_scan.py

# 扫描指定网段多个端口并导出结果
python lan_scan.py -n 192.168.1.0/24 -p 80,443,22 -o result.txt

# 加快扫描（更短超时、更多线程）
python lan_scan.py -t 0.3 -w 100
```

## 示例输出

```
✅ 192.168.1.1 (router.home): 80, 443
✅ 192.168.1.100 (nas.local): 80

结果已导出到 result.txt
```
