# 局域网IP扫描工具 lan-scanner

## 项目介绍
基于 Python 标准库实现的轻量级局域网存活主机扫描工具，无需安装第三方依赖，通过探测 80 端口判断主机是否在线。

## 功能特性
- 支持任意网段（CIDR 格式），默认 `192.168.1.0/24`
- 50 线程并发扫描，速度更快
- 纯 Python 标准库实现，零额外依赖
- 跨平台，Windows / Linux / macOS 均可运行

## 运行环境
- Python 3.7 及以上版本

## 使用方法
1. 将仓库克隆或下载到本地
2. 在终端中运行脚本
   ```bash
   python lan_scan.py
   ```
3. 按提示输入要扫描的网段（如 `192.168.1.0/24`），直接回车使用默认网段

## 示例输出
```
正在扫描网段: 192.168.1.0/24
✅ 在线: 192.168.1.1
✅ 在线: 192.168.1.100

扫描结束，共找到 2 台开放80端口的设备
```
