# 局域网IP扫描工具 lan-scanner

## 项目介绍
基于Python标准库实现的轻量级局域网存活主机扫描工具，无需安装第三方依赖，一键扫描内网存活设备并自动识别主机名，支持结果导出。

## 功能特性
- 快速扫描C类网段254个IP地址
- 自动识别存活主机的主机名
- 扫描结果自动导出为TXT文件
- 纯Python标准库实现，零额外依赖
- 适配Windows系统，开箱即用

## 运行环境
- Python 3.7 及以上版本
- Windows 操作系统

## 使用方法
1. 将仓库克隆或下载到本地
2. 打开 `lan_scan.py`，修改末尾的 `subnet` 参数为你的局域网网段
3. 在终端中运行脚本
   ```bash
   python lan_scan.py
